# SOP: Agent Deployment

1. Define the agent's role and non-goals.
2. List tools and grant least-privilege permissions.
3. Define input/output schemas and handoff contracts.
4. Set time, token, tool-call, and monetary budgets.
5. Require approval for external or irreversible actions.
6. Add injection defenses and treat retrieved content as untrusted.
7. Test happy path, tool failure, malicious input, timeout, and duplicate execution.
8. Enable full audit logging.
9. Stage deployment and monitor.
10. Maintain a kill switch and manual operating procedure.
