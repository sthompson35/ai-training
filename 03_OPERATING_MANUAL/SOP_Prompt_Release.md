# SOP: Prompt Release

1. Create a versioned prompt specification.
2. Define task, allowed sources, prohibited behavior, and output schema.
3. Build representative, adversarial, and boundary test cases.
4. Run baseline and candidate prompts against the same test set.
5. Score quality, groundedness, format compliance, safety, latency, and cost.
6. Obtain independent review for Tier 2+ use cases.
7. Release behind a feature flag.
8. Monitor regression metrics.
9. Roll back immediately if critical thresholds fail.
10. Preserve prompt, results, approver, and change rationale.
